# Legacy Bash Scripts

This directory contains legacy bash scripts and configuration files that are no longer actively maintained but kept for reference.

## Contents

- **binaries/** - Legacy bash scripts (WabbajackProton.sh, WabbajackWine.sh, omni-guides.sh)
- **files/** - Wine registry files and DLL files used by legacy scripts

## Status

These scripts are **deprecated** and have been replaced by the Python-based Jackify application. They are preserved here for:
- Historical reference
- Users who prefer manual installation methods
- Debugging legacy configurations

## Migration

If you're still using these scripts, please consider migrating to the main Jackify application which provides:
- Automated installation process
- GUI and CLI interfaces
- Better error handling and logging
- Active maintenance and updates

See the main [README.md](../README.md) for current installation instructions.
